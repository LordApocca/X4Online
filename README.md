# X4: Online

Online multiplayer for X4: Foundations, for up to 8 players. This mod is NOT currently accessible to non-testers.

Download `X4Online-win-x64.zip` from the [latest release](https://github.com/LordApocca/X4Online/releases/latest), unzip it and run `X4Online.exe`. The app installs the mod and keeps itself up to date.

X4: Online is an unofficial fan project, not affiliated with Egosoft GmbH.
